# 场景需求卡 Schema（S3 字段口径）

S4 组合器直接消费本表结构。每条场景卡必须完整包含以下字段。

| 字段 | 定义 | 合格样例 | 不合格样例 |
|---|---|---|---|
| scene_id | 场景编号 | SC-01 | — |
| scene_name | 场景名（动词性、有画面） | 聚会合照 C 位 | 日常穿搭 |
| persona_id / bp_id | 关联人群（S2）与买点（S1） | 人群① × BP-01 | — |
| trigger | 触发时刻：具体时间/地点/事件（至少两个要素） | 面试当天早上、退租前一天 | 需要的时候 |
| picture | 场景画面：人物/环境/动作/冲突，能开机就拍 | 出租屋镜子前先穿恨天高扶墙皱眉，换丑萌鞋站直显长 | 展现产品优点 |
| pain | 具体痛点（有画面感） | 合照永远被安排站后排踮脚 | 不方便、不好用 |
| shoot | 拍摄建议：镜头 + 第一视角 + 口播钩子 | 变装卡点；"合照永远站后排？不是你的问题，是鞋的问题" | 拍个视频宣传一下 |
| verify | 内容侧验证（一行） | ✓ 面试变装 4.9k 赞模板 | — |
| priority | 主攻 / 可测试 / 待确认 | 主攻 | — |

## 优先级判定规则

- **主攻** = 已验证爆款模板 + Tier1 人群买点
- **可测试** = 有内容信号但无爆款模板，或人群/买点非 Tier1
- **待确认** = 内容侧有信号但缺商品事实确认（必须标注"需商家确认什么"，如鞋楦宽度）

## 每轮产出下限

- 主攻 ≥ 4 张（含至少 1 张命中已验证模板的场景）
- 可测试 ≥ 2 张
- 同质场景（2 张以上）必须合并，不注水

## 已跑通的爆款模板类型（命中即升主攻）

| 模板 | 品类示例 | 特征 |
|---|---|---|
| 变装卡点 | 女鞋/服装 | 换装瞬间切换，前后对比 |
| 同学/朋友种草 | 女鞋 | "你穿的是什么鞋"问答式 |
| 统一条件三段实测 | 清洁/家电 | 喷→等→擦，同机位前后对比 |
| 价格冲突 | 3C 高客单 | 前 2 秒制造损失感 + 具体数字 |
| 收纳空间翻倍 | 出行/箱包 | 沉浸式收拾行李 |
| 柜姐测评 | 轻奢包袋 | 尺寸/真假/颜色逐一讲解 |
| 职业痛点实测 | 健康/功能品 | 护士/教师/久站人群下班体感 |
| "久吹不头疼"型 | 小家电 | 直接回应品类常见抱怨 |
