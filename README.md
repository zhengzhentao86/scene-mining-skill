# 抖音「挖掘场景」Skill · 学员使用说明

> 你是做抖音电商内容的。这个 Skill 帮你解决另一个最头疼的问题：
> **这条视频，到底该拍什么画面？**

---

## 它能帮你做什么

给它一份"商品买点 + 目标人群"，它会告诉你：

- 你的商品，**大家在什么时刻会想起它**（宿舍断电、面试早上、退租前一天……）
- 每个场景**画面怎么拍**——具体到"能开机就拍"的程度，不是"展现产品优点"这种废话
- 每句**口播钩子**怎么讲（第一句话说什么能留住人）
- 每个场景是不是**真的在抖音上火**（挂着真实视频的标题和点赞数，不是瞎编）

一句话：**商家脑子里只有"我的产品好在哪"，这个 Skill 帮你翻译成"该拍哪个画面、怎么拍"。**

---

## 你需要准备什么

最好有上一步的两样东西：

1. **买点清单**（「卖点转买点」Skill 的产出：这个商品让人掏钱的理由）
2. **人群匹配表**（「挖掘人群」Skill 的产出：这个商品最该卖给谁）

两个都有，场景挖得最准。
**如果都没有**——直接把商品的主图/详情页/一段介绍文字贴给它也行，它会先快速抓出核心卖点和人群，再挖场景（结果会标注"简版"）。

> 整套流程是固定的四步：卖点 → 买点 → 人群 → 场景。这个 Skill 是第三步。

---

## 三步上手

**第 1 步 · 安装**
把整个 `scene-mining` 文件夹（里面有个 `SKILL.md` 的那个），放进你豆包的 Skills 目录里。
不会找目录？问你的课程老师要"Skill 安装指引"，或看课程配套视频，一分钟装好。

**第 2 步 · 打开豆包，说一句话**
> "用一下挖掘场景这个 Skill，这是我的买点清单和人群匹配表："
> 然后把你的两个文件（或文字）贴进去。

**第 3 步 · 等结果**
它会自动去抖音上核实这些场景是不是真的有人看，最后给你一个 HTML 文件——**场景需求卡**，用浏览器打开就能看。

---

## 你会拿到什么

一份"场景需求卡"，里面有 **6 张以上场景卡**。每张卡就四行，扫一眼读完：

| 行 | 写的是 | 你拿去干嘛 |
|---|---|---|
| **触发时刻** | 什么时间/地点/事件会想起它 | 决定视频开头拍什么 |
| **场景画面** | 谁在做什么、什么环境、什么冲突 | 照着这个画面开机就拍 |
| **具体痛点** | 不用它的麻烦是什么 | 写脚本时知道戳哪 |
| **拍法 + 口播** | 镜头怎么走 + 第一句话说什么 | 直接抄成脚本 |

每张卡下面还有一行 **`✓ 已验证`**——那是抖音上真有这个场景、且真有播放量的证据（附真实视频标题和点赞数）。没验证的场景会标"蓝海待测"，让你知道这方向没人拍、值得试。

每张卡还会标一个结论：

- 🟠 **主攻** = 已有人验证过能火的场景，优先拍
- 🔵 **可测试** = 有信号但还没爆款，值得试
- ⚪ **待确认** = 需要先问商家一个具体问题（比如"这个鞋到底有多宽"）

---

## 常见问题

**Q：我不会用 GitHub，能拿到这个 Skill 吗？**
A：能。你不用碰 GitHub。拿别人发给你的 zip 压缩包，解压，把 `scene-mining` 文件夹放进豆包的 Skills 目录就行。GitHub 只是存放的地方，和你无关。

**Q：挖出来的场景感觉还是有点宽？**
A：把输入再具体一点——人群表里选 1 个最主攻的人群，买点选 2-3 条最强的，单独喂它再跑一次，场景会明显变细。

**Q：它说"待确认"，是什么意思？**
A：抖音上确实有人在问这件事，但商品资料里没写答案。去问商家一句，把答案补给它，它就能把这张卡升级成主攻。

**Q：要先跑前面两个 Skill 吗？**
A：推荐先跑（卖点转买点 → 挖掘人群 → 挖掘场景），结果最准。赶时间的话直接贴商品资料也能出简版，但先跑一遍更值。
